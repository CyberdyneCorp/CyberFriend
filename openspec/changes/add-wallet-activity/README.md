# add-wallet-activity

"O que essa carteira fez essa semana?" -- what a wallet did over the last days
on Ethereum, Base and Arbitrum, classified without a model and answered
verbatim.

Same clearance as the positions tools: the address must be one the asker typed
or saved. New here: the time window is read from the asker's question, never
from the model's arguments, and a clearance now carries whether only the asker
will read the answer, so counterparties are written out in a DM and redacted
in a channel.

- `proposal.md` -- why, what changes, and the risk
- `design.md` -- the endpoint, the cursor trap, the classifier and the privacy rule
- `specs/wallet-activity/spec.md` -- the requirements
- `tasks.md` -- progress
