# add-feature-requests

Let people suggest features from Discord, with `/suggest`, or with an explicit
suggestion form such as "tenho uma sugestão", "sugestão:", "feature request:"
or "it would be nice if you could", always confirmed with a button. Anything
another feature would handle wins. The
suggestions are stored, listed back to the person with `/suggestions`, and
triaged by status in the admin console. The person gets a DM when the status
changes, if they asked for one.

- `proposal.md`: why, and what changes
- `design.md`: routing, the data model, the text rules, triage
- `specs/feature-requests/spec.md`: the requirements
- `tasks.md`: progress
