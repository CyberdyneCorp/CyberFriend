# add-full-name-and-introductions

People introduce themselves in one message: name, what to call them, email,
phone, where they live. Each of those was only recognised on its own, so an
introduction was treated as a question, answered from the corpus, and --
worse -- kept in conversation memory with the email and phone in it.
