# add-richer-facts

A production introduction -- full name, nickname, age, birth date, phone,
address, wallet and email in one DM -- saved only the full name, and refused
the phone as "too long". This change makes introductions robust, adds a home
address and a birth date, and lets a person save several wallets.

- `proposal.md` -- why, what changes, and the risk
- `design.md` -- the data model (migration 0022) and the privacy rules
- `specs/personal-facts/spec.md` -- the requirements
- `tasks.md` -- progress
