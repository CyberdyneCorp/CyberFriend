# add-cyberwealth-personal-keys

A person's own CyberWealth connected-app key (`cwk_live_...`), taken in a DM
and stored encrypted, so CyberWealth's `my_*` tools answer that person, in
their DMs, with their own key. Partner guide D10 item 2, deferred by
`add-cyberwealth-federation`.

- `proposal.md`: why, and what changes
- `design.md`: storage and encryption, where the key travels, registration of
  tools the service principal cannot list, what a channel message gets
- `specs/cyberwealth-personal-keys/spec.md`: the requirements
- `tasks.md`: progress
